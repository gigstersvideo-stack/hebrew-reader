# Changelog — Hebrew Reader

Формат версий: v<крупное>.<новая функция>.<мелкий фикс> — примерно по смыслу,
не строгий semver.

## v1.10.0
- Владельческий режим редактирования: секретный параметр `?owner=...` в
  ссылке открывает скрытый переключатель в настройках, разрешающий править
  базовые книги (демо-текст, книги из `books-manifest.json`). У обычных
  посетителей этот переключатель не отображается вообще.
- Значок правки (✎) теперь виден по умолчанию только на "своих" книгах
  (загруженных через "Добавить свою книгу") — это чужие данные никто
  без ключа не трогает.

## v1.9.0
- Редактирование предложения прямо на сайте: значок ✎ у предложения
  открывает окно с JSON этого предложения, правится любое поле.
- Загрузка картинки к предложению прямо из окна редактирования
  (конвертируется в data-URL, вставляется в поле `illustration.img`).
- Кнопка "Сообщить о проблеме" (🐞, нижний левый угол) — открывает
  предзаполненный GitHub Issue с диагностикой (браузер, страница, время).
- Обложки книг: при импорте своей книги можно приложить картинку-обложку,
  отображается на карточке в библиотеке вместо цветного прямоугольника.

## v1.8.0
- Импорт книги прямо в браузере: файл или вставленный JSON проверяется на
  валидность (понятные ошибки на русском) и сохраняется в localStorage —
  ничего не отправляется на сервер. Библиотека собственных книг живёт
  только в браузере конкретного человека.
- Это же решает вопрос авторских прав при публичном хостинге: сам движок
  публичный, тексты книг — только у пользователя локально.

## v1.7.0
- Пагинация: книга режется на страницы по 20 предложений вместо одного
  длинного полотна текста. Кнопки ‹ ›, счётчик страницы.
- Закладки: последняя открытая страница сохраняется отдельно для каждой
  книги, восстанавливается при следующем визите.
- Плеер при воспроизведении сам переключает страницу, если проигрываемое
  предложение оказалось на другой — аудио и текст не расходятся.
- Иллюстрации переведены на данные конкретной книги (`s.illustration`)
  вместо общего списка на весь сайт — чинит баг, когда картинки демо-текста
  показывались поверх Гарри Поттера. Добавлена поддержка img/gif, не только
  нарисованного SVG.

## v1.6.0
- Библиотека с несколькими книгами: экран выбора книги, карточки,
  `books-manifest.json` для подключения книг файлами.
- Словарь/частотность/покрытие теперь привязаны к конкретной книге
  (раньше слова из разных книг могли смешиваться).

## v1.5.0
- Автопрокрутка экрана к читаемому предложению во время воспроизведения,
  с переключателем в настройках.

## v1.4.0
- Данные книги подгружаются из внешнего `book-data.json` через `fetch()`
  вместо того, чтобы быть зашитыми в код — с откатом на встроенное демо,
  если файла нет рядом.

## v1.3.0
- Иллюстрации + мнемоника для ключевых слов (изначально только для
  тренировочного текста): SVG-картинка, подпись, приём запоминания слова.

## v1.2.0
- Тренировка по сохранённым словам (флэш-карты), экспорт словаря в Anki,
  частотный список слов книги с "процентом покрытия" известной лексики.
- Настройки отображения: огласовки / дословный перевод / подробный разбор
  слова — включаются и выключаются независимо.

## v1.1.0
- Перевод на русский (был плачевный английский демо-перевод).
- Починен баг с кликом по второму слову подряд (переписан обработчик
  клика вне текста).
- Два перевода предложения: дословный (слово-в-слово) и литературный.
- Сохранение слов в личный словарь (позже в v1.8 перевели на настоящее
  постоянное хранилище браузера — раньше работало только внутри
  превью-окна Claude).

## v1.0.0
- Первый прототип: одна тренировочная история на иврите, клик по слову —
  перевод в подсказке, клик по предложению — перевод, фейковый плеер
  синхронизирует подсветку слов с "чтением" (реальное аудио ещё не
  подключено).
