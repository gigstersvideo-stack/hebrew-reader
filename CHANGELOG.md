# Changelog — Hebrew Reader

Формат версий: v<крупное>.<новая функция>.<мелкий фикс> — примерно по смыслу,
не строгий semver.

## v1.22.0
- (Пайплайн, не сам сайт) Новый `illustrate_book.py`: добавляет 2-3
  иллюстрации-мнемоники к уже размеченному `book-data.json`. Слово для
  иллюстрации выбирается не наугад, а по настоящей частотности —
  сверкой с частотными списками иврита от Dicta (top_500/top_20000):
  редкое и при этом значимое для сюжета слово, имена персонажей и
  служебные части речи (предлоги/частицы/местоимения) исключены.
  Мнемоника (созвучие с русским + абсурдная сценка) пишется через
  Gemini, а картинка рисуется настоящей диффузионной моделью через
  Cloudflare Workers AI (`@cf/black-forest-labs/flux-1-schnell`,
  бесплатно в рамках дневного лимита нейронов) — SVG для этого не
  подошёл, текстовая модель не может достоверно нарисовать конкретное
  действие/сценку, только настроение и цвет.
- Обе опубликованные истории фермы ("Рони и кот", "Пропавшая книга")
  дополнены такими иллюстрациями через уже существовавшее в движке
  поле `illustration.img` — правок в сам `reader-prototype.html` не
  понадобилось.
- (Задним числом, не залогировано вовремя) `2_generate_story.py`
  изначально появился как раз для генерации самого текста истории
  под уровень ульпана — до того, как в v1.21.0 в него добавили ещё и
  рисование обложки.

## v1.21.0
- Обложки книг в библиотеке: вместо однотонного прямоугольника с
  названием — минималистичная line-art SVG-иконка по сюжету книги
  (тот же визуальный язык, что у иллюстраций в тексте: тонкие контуры,
  золотой акцент, цвета через var(--ink)/var(--gold)). Полоска-баннер
  стала выше (90px → 130px), чтобы иконке было где дышать.
- `2_generate_story.py` теперь заодно рисует обложку — Gemini выдаёт
  готовый SVG-код в том же вызове, что и текст истории, бесплатно
  (полноценная генерация растровых картинок через Gemini на бесплатном
  тарифе оказалась недоступна без включённого биллинга — SVG текстом
  через уже используемую бесплатную модель обошёл это ограничение).

## v1.20.2
- Тумблер "Огласовки" в настройках теперь действительно убирает никуд из
  текста самой книги, а не только из словарной формы слова во всплывающей
  подсказке (как было изначально) — раньше это работало так, потому что
  тестовый текст никогда не имел огласовок в самих словах предложения,
  теперь, когда появились полностью вокализованные книги (демо
  через edge-tts, "фермерские" истории), ограничение стало заметным багом.

## v1.20.1
- Починен баг: если открыть книгу, начать играть аудио и вернуться в
  библиотеку без паузы, а потом открыть другую книгу — старое аудио
  продолжало звучать одновременно с новым (плеер не останавливал
  предыдущий `<audio>` при переключении). Теперь при открытии любой
  книги все чужие/старые аудио на странице принудительно
  останавливаются и удаляются.

## v1.20.0
- Демо-текст ("אות מהחלל") вынесен из тела HTML в отдельный
  `demo-book-data.json`, подключается через `books-manifest.json` —
  ровно так же, как любая другая книга. Движок больше не хранит
  внутри себя данные ни одной конкретной книги — файл страницы стал
  почти на треть легче (111 КБ → 76 КБ).

## v1.19.0
- Демо-текст ("אות מהחלל") наконец озвучен — через бесплатный edge-tts
  (голос he-IL-AvriNeural), с точными таймингами слов из событий
  синтеза речи, без Whisper и без ручного выравнивания. Раньше
  проигрывался только оценочный таймер (0.42 сек/слово).
- Новый скрипт `3_generate_audio.py`: озвучивает любой book-data.json
  без готовой аудиокниги (пока нет реальной начитки) — на вход
  предложения со словами, на выходе mp3 по предложению + тайминги
  каждого слова, проставленные прямо в JSON.

## v1.18.0
- Импорт книги: если в JSON есть поле `title` на верхнем уровне, оно
  само подставляется в поле "Название книги" (можно поправить руками
  перед сохранением) — не нужно каждый раз вбивать название заново.

## v1.17.0
- Прямая ссылка на книгу: `reader-prototype.html?book=<URL к твоему
  приватному book-data.json>&title=Название` открывает книгу сразу,
  минуя библиотеку. Сам сайт остаётся публичным и ничего не хранит —
  книга (текст + аудио, если в JSON указаны абсолютные ссылки на клипы)
  живёт только там, куда указывает ссылка. Работает с любого устройства,
  где открыта эта ссылка — решает вопрос доступа из интернета без
  публикации чужого контента и без необходимости повторно загружать
  файлы на каждом устройстве.
  Важно: хостинг книги должен отдавать CORS-заголовки для fetch()
  (Cloudflare Pages/Netlify — да по умолчанию; прямые ссылки Google
  Drive/Dropbox — не всегда надёжно).

## v1.16.0
- Подсветка слова теперь считается через requestAnimationFrame (~60 раз
  в секунду) вместо нативного события timeupdate у аудио (браузеры сами
  троттлят его примерно до 4 раз в секунду) — вместе с уже имеющимся
  CSS-переходом на .tword подсветка ощущается как плавное перетекание,
  а не скачок с одного слова на другое.

## v1.15.0
- Полоска внизу больше не показывает прогресс одного короткого клипа
  (2-3 секунды) — теперь это ряд отдельных сегментов, по одному на
  каждое предложение текущей страницы. Пройденные предложения полностью
  залиты золотым, текущее заполняется по ходу воспроизведения, будущие
  пустые. Клик по любому сегменту сразу переключает и играет то
  предложение — навигация по странице целиком, а не только вперёд-назад
  по одному клипу.

## v1.14.0
- Клик по слову теперь ставит аудио на паузу — раньше звук продолжал
  играть, пока читаешь подсказку перевода, и подсветка убегала вперёд.
- В подсказке слова — кнопка "▶ Слушать отсюда": запускает воспроизведение
  с начала предложения, к которому относится это слово. Так после паузы
  на любом слове можно легко возобновить чтение именно с того места, а
  не искать вручную, где остановился общий плеер.
- (Скрипт 4_align_real_audio.py, не сам сайт) Починена интерполяция
  таймингов для слов, которые Whisper не распознал напрямую: раньше
  такому слову присваивалась ТОЧКА времени (start == end), из-за чего
  оно физически не могло подсветиться в плеере — подсветка перескакивала
  через него на следующее реально совпавшее слово. Теперь время разрыва
  честно делится между всеми пропущенными словами внутри него.

## v1.13.0
- Настоящее аудио вместо тестового таймера: если у предложения есть
  сгенерированный mp3-файл (см. `3_generate_audio.py`), плеер теперь
  проигрывает именно его, подсвечивая слова по настоящим таймкодам
  вместо приблизительного расчёта по 0.42 сек/слово.
- Механика воспроизведения переписана на "по предложению за раз":
  один <audio>-элемент, при окончании клипа автоматически переходит
  к следующему предложению (с переключением страницы, если нужно).
- Предложения без готового аудио (демо-текст, ещё не озвученные главы)
  продолжают работать через прежний оценочный таймер — сайт не
  ломается на книгах без озвучки.
- Новый скрипт `3_generate_audio.py`: озвучивает уже размеченный
  `book-data.json` через бесплатный edge-tts (без Whisper и без
  отдельного шага выравнивания) — тайминги слов идут прямо из
  событий синтеза речи.

## v1.12.0
- Кнопка "🗑 Убрать картинку" в окне правки предложения — удаляет поле
  illustration из JSON одним кликом, без ручного редактирования текста.

## v1.11.0
- Значок правки (✎) больше не показывается на своих книгах "из коробки" —
  теперь и для них нужен отдельный переключатель "Режим редактирования" в
  настройках (виден всем, не только владельцу). Владельческий переключатель
  для базовых книг остался отдельным и по-прежнему скрыт от обычных
  посетителей.

## v1.10.0
- Владельческий режим редактирования: секретный параметр `?owner=...` в
  ссылке открывает скрытый переключатель в настройках, разрешающий править
  базовые книги (демо-текст, книги из `books-manifest.json`). У обычных
  посетителей этот переключатель не отображается вообще.
- Значок правки (✎) теперь виден по умолчанию только на "своих" книгах
  (загруженных через "Добавить свою книгу") — это чужие данные никто
  без ключа не трогает.

## v1.9.0
- Редактирование предложения прямо на сайте: значок ✎ у предложения
  открывает окно с JSON этого предложения, правится любое поле.
- Загрузка картинки к предложению прямо из окна редактирования
  (конвертируется в data-URL, вставляется в поле `illustration.img`).
- Кнопка "Сообщить о проблеме" (🐞, нижний левый угол) — открывает
  предзаполненный GitHub Issue с диагностикой (браузер, страница, время).
- Обложки книг: при импорте своей книги можно приложить картинку-обложку,
  отображается на карточке в библиотеке вместо цветного прямоугольника.

## v1.8.0
- Импорт книги прямо в браузере: файл или вставленный JSON проверяется на
  валидность (понятные ошибки на русском) и сохраняется в localStorage —
  ничего не отправляется на сервер. Библиотека собственных книг живёт
  только в браузере конкретного человека.
- Это же решает вопрос авторских прав при публичном хостинге: сам движок
  публичный, тексты книг — только у пользователя локально.

## v1.7.0
- Пагинация: книга режется на страницы по 20 предложений вместо одного
  длинного полотна текста. Кнопки ‹ ›, счётчик страницы.
- Закладки: последняя открытая страница сохраняется отдельно для каждой
  книги, восстанавливается при следующем визите.
- Плеер при воспроизведении сам переключает страницу, если проигрываемое
  предложение оказалось на другой — аудио и текст не расходятся.
- Иллюстрации переведены на данные конкретной книги (`s.illustration`)
  вместо общего списка на весь сайт — чинит баг, когда картинки демо-текста
  показывались поверх Гарри Поттера. Добавлена поддержка img/gif, не только
  нарисованного SVG.

## v1.6.0
- Библиотека с несколькими книгами: экран выбора книги, карточки,
  `books-manifest.json` для подключения книг файлами.
- Словарь/частотность/покрытие теперь привязаны к конкретной книге
  (раньше слова из разных книг могли смешиваться).

## v1.5.0
- Автопрокрутка экрана к читаемому предложению во время воспроизведения,
  с переключателем в настройках.

## v1.4.0
- Данные книги подгружаются из внешнего `book-data.json` через `fetch()`
  вместо того, чтобы быть зашитыми в код — с откатом на встроенное демо,
  если файла нет рядом.

## v1.3.0
- Иллюстрации + мнемоника для ключевых слов (изначально только для
  тренировочного текста): SVG-картинка, подпись, приём запоминания слова.

## v1.2.0
- Тренировка по сохранённым словам (флэш-карты), экспорт словаря в Anki,
  частотный список слов книги с "процентом покрытия" известной лексики.
- Настройки отображения: огласовки / дословный перевод / подробный разбор
  слова — включаются и выключаются независимо.

## v1.1.0
- Перевод на русский (был плачевный английский демо-перевод).
- Починен баг с кликом по второму слову подряд (переписан обработчик
  клика вне текста).
- Два перевода предложения: дословный (слово-в-слово) и литературный.
- Сохранение слов в личный словарь (позже в v1.8 перевели на настоящее

## v1.0.0
- Первый прототип: одна тренировочная история на иврите, клик по слову —
  перевод в подсказке, клик по предложению — перевод, фейковый плеер
  синхронизирует подсветку слов с "чтением" (реальное аудио ещё не
  подключено).
